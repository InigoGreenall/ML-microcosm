## Build Instructions (user)
```
$ git clone https://github.com/InigoGreenall/ML-microcosm
$ cd ML-microcosm
$ mkdir build && cd build
$ cmake ..
$ make
```
## Build Instructions (development / debug)
```
$ git clone https://github.com/InigoGreenall/ML-microcosm
$ cd ML-microcosm
$ ./devbuild.sh
$ cd build
$ make
```
